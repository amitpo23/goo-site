# GOO

אתר החברה. עמוד אחד בעברית (RTL), Next.js עם יצוא סטטי.

## עריכת תוכן

כל הטקסטים, המיזמים, הלקוחות ופרטי הקשר נמצאים בקובץ אחד: `content/site.ts`.

- **פרטי קשר**: ממלאים `contact.whatsapp` ו-`contact.email`. כפתור מוצג רק כשיש ערך.
- **לוגואים של לקוחות**: שמים קובץ ב-`public/clients/` ומוסיפים שורה ל-`clients`. האזור "עסקים שאנחנו מלווים" מופיע רק כשהרשימה לא ריקה.
- **רקע של יובל**: השדה `text` שלו ב-`founders`.

## סריקה בגוגל

האתר מסומן `noindex`. כדי לפתוח לסריקה מוחקים את שורת `robots` ב-`app/layout.tsx`.

## הרצה

```sh
npm ci
npm run dev
npm run build   # הפלט ב-out/
```

## עיצוב

- צבעים וטיפוגרפיה מוגדרים בראש `app/globals.css`.
- מפת קווי הגובה מחושבת בזמן הבנייה ב-`components/Contours.tsx`. מיקומי הפסגות בפתיח מוגדרים בראש `app/page.tsx`.
- פונטים: Frank Ruhl Libre לכותרות, IBM Plex Sans Hebrew לטקסט. שניהם נארזים עם האתר.
